# 3D Endless Runner

A simple 3D endless runner built in Unity where the player automatically moves forward while avoiding randomly generated obstacles. The game becomes progressively more challenging as the player's speed increases over time.

## Features

- Endless runner gameplay
- Automatic forward movement
- Horizontal player controls
- Random obstacle generation
- Progressive difficulty
- Score tracking
- Game over screen with sound effects

## Built With

- Unity
- C#
- TextMeshPro

## Controls

| Action | Key |
|--------|-----|
| Move Left | A / Left Arrow |
| Move Right | D / Right Arrow |
